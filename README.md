# 浙江教师招聘 · 结构化面试真题库 & AI 模拟考官

在线使用：https://jck19924362.github.io/zj-structured-interview/

一个浏览器页面搞定结构化面试备考的全部练习——真题库、AI 模拟考官打分、每日打卡、间隔复习、收藏。

## 它能做什么

- 📚 308 道浙江教师招聘结构化面试真题，按**地市 / 七大题型 / 真题来源**筛选，支持关键词搜索、随机抽题
- 🎯 AI 模拟考官随机抽题，按 **7 个维度**智能打分（应变 / 计划 / 沟通 / 逻辑 / 创新 / 语言 / 仪表），附改进建议
- 🧭 每题自带**专业答题骨架**（应急/组织/人际/自我认知/综合分析/教育教学/时政 七大题型各有框架），不再"词穷"
- 📅 每日打卡：每天抽 2 题练习，支持文字 / 录音 / 视频作答，打卡日历 + 连续天数 + 里程碑徽章
- 🔁 间隔复习：练过的题按记忆曲线（1/3/7/14/30 天）到点提醒重练，对抗遗忘
- ⭐ 收藏难题，支持一键导出 / 打印复习
- 📈 AI 考官打分历史自动画折线趋势图，看自己进步曲线

## 数据说明

- 覆盖浙江 11 个地市，数据整理自各地教育局 / 人社局公开招聘公告原文
- 每题标注来源置信度（**真题** / **机构模拟题** / **经典练习**），考前可一键只看真题
- 当前在库 308 题（2024–2026 届为主），新公告发布后将持续更新
- 数据来源于考生回忆版，仅供参考，**报名前请务必以公告原文为准**

## 技术实现

纯前端三件套（HTML + JS + JSON 数据），无后端、无构建、无依赖，GitHub Pages 直接托管，所有计算在浏览器本地完成。

## 使用提示

- 录音 / 摄像头权限需要 **HTTPS 或 localhost** 环境（GitHub Pages 默认 HTTPS，可直接用）
- 答题记录、打卡、复习进度、录音全部存在浏览器本地，不上传服务器
- 想换电脑继续练：在原电脑浏览器开发者工具的 Application → Local Storage 导出 `zj_*` 开头的键
